### 🔬 Research & Projects

#### 🧠 HypnoTrust — EEG Sleep Stage Classification

A research-oriented machine learning project exploring automated sleep-stage classification using EEG recordings from the Sleep-EDF dataset.

**Research focus:**
- EEG signal processing and feature extraction
- Sleep-stage classification and temporal context
- Probability calibration and prediction uncertainty
- Selective prediction and human-in-the-loop review
- Subject-wise evaluation and reproducibility

#### 👁️ RetinaTrust — Retinal Image Analysis

An experimental project investigating the reliability of machine learning models for diabetic retinopathy image classification.

**Research focus:**
- Biomedical image analysis
- Classification performance and error analysis
- Model calibration and uncertainty
- High-confidence prediction failures
- Transparent and reproducible evaluation

*Both projects are research prototypes and are not intended for clinical use.*
